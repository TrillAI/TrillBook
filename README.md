# Mike Hunt's Big Night In

An eight-page, square illustrated storybook for grown-ups, with one sentence per page. Open **Mike Hunts Big Night In.pdf** to read it.

The illustrations are in `art/`. To rebuild the PDF, install Python's `reportlab` package and run `python make_book.py` (the script uses the DejaVu Serif Bold font at `/usr/share/fonts/truetype/dejavu/DejaVuSerif-Bold.ttf`).
